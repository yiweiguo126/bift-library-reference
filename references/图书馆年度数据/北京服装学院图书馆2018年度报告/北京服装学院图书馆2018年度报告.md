## 转换说明

1. 页面由前端 Vue 渲染，静态 HTML 只有占位提示「当前内容加载异常」与模板变量。文章数据内嵌在页面脚本的 `data` 对象中，其中 `content` 字段仅含三个 `<img>` 标签，没有文字节点。
2. 按 huashu-md-html 技能的能力分流判断：这是图片型正文页，纯 HTML 转换只能得到图片引用（`skeleton.md`），因此追加图片识别路径。
3. 三张原图按 1800 px 高度切为 28 片，用 macOS Vision 做中英文 OCR，得到 606 行带坐标的文本；再用图像逐页校订表格、榜单和数值，过滤页眉馆名、重复目录页和图表图形噪声。
4. 图表类页面没有独立文字段落，本文把图表标题、图例年份和数值标签整理成表格；折线图未标注逐点数值，只保留趋势与坐标轴说明。
5. 原页面发布时间为 2022-09-03 10:30，报告内容年份为 2018。页面数据字段显示更新时间 2026-01-31，属门户维护信息，不是报告发布日期。
