## 一、资源建设

### 资源总体概况

对标国际一流时尚高校，服务学校一流学科建设，聚焦国内外高端文献资源。截至2019年底，图书馆纸质藏书78.4万余册，中外文期刊513种，电子图书317万余册，电子期刊6.8万种，多媒体资料2万余部，各种购买及自建数据库90余个。

### 2019年新增纸质图书

- 开放办馆，师生参与，需求导向，保障图书采购质量。
- 2019年新增纸质图书3,6714册，同比增长30.5%。

2017—2019年馆藏纸质图书增量：2017年31256册、2018年28124册、2019年36714册。图中另有中文图书（2017-2019）26863 / 26992 / 35017，外文图书（2017-2019）1393 / 1643（中间年份数值被图形遮挡）。

- 新阶段，保障师生阅读需求，中文图书持续增长，较2017年增长30.4%。
- 新突破，为更好服务学校一流学科建设，增加外文图书，较2017年增长17.9%。

## 二、读者服务

### 2019年接待人次

- 2019年全馆开放324天，近5000小时。
- 全年接待读者134866人次，日均416人次。
- 北校区分馆接待读者27710人次，日均86人次。
- 总阅览64044人次，日均阅览198人次。

## 转换说明

1. 页面由前端 Vue 渲染，静态 HTML 只有占位提示与模板变量。文章数据内嵌在页面脚本的 `data` 对象中，其中 `content` 字段仅含三个 `<img>` 标签，没有文字节点。
2. 按 huashu-md-html 技能的能力分流判断：这是图片型正文页，纯 HTML 转换只能得到图片引用（`skeleton.md`），因此追加图片识别路径。
3. 三张原图均为 1920×16200，按 1800 px 高度切为 27 片，用 macOS Vision 做中英文 OCR，得到 985 行带坐标的文本；再用图像逐页校订表格、榜单和数值，过滤页面装饰与图形噪声。
4. 图表类页面没有独立文字段落，本文把图表标题、图例年份和数值标签整理成表格；折线图未标注逐点数值，只保留趋势与坐标轴说明。
5. 原页面发布时间为 2022-09-03 10:31，报告内容年份为 2019。页面数据字段显示更新时间 2026-03-01，属门户维护信息，不是报告发布日期。
6. 与 2018 年度报告相比，2019 年度数据增加了资源建设经费、学科分布、空间预约、信息素养教育、微信公众号阅读榜、院系到馆榜和入馆教育通关率等内容，章节结构为资源建设、读者服务、微服务、荣誉榜单四部分。
