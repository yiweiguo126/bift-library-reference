# 北服图书馆参考咨询 Skill（bift-library-reference）

> **适用对象**：本 Skill 适合北京服装学院图书馆的读者使用，包括在校师生、退休教师、校友、校外读者，以及关注北服图书馆资源与服务的各界人士。

这是一个面向北京服装学院图书馆参考咨询场景的 WorkBuddy Skill。它以自然亲切的馆员口吻工作：先帮助提问者把问题问准，再依据授权信息源给出可核对的简短答案；涉及资源使用方式时完整照录馆方原文，涉及统计、合并与基于原文的日期推算／逻辑推演时逐项标注来源、处理过程与推算性质。Skill 自足运行，不依赖外部项目文件。

## 它能回答什么

| 主题 | 典型问题示例 |
|---|---|
| 馆藏与检索 | 查某本书有没有、书刊检索、新书通报、读者中心续借、读者留言荐购 |
| 借阅服务 | 借几册、借多久、逾期占用费、馆藏分布、代借、通借通还、馆际互借、文献传递 |
| 空间与设备 | 开放时间、研学空间与教师阅享（阅享）空间、研讨室、座位预约、存包柜、静音舱 |
| 数字资源 | 中国知网、WGSN、读秀等 52 个已登记资源的访问与使用条件、账号注册、校外使用；可按原文规则推算账号开通时点 |
| 学习支持 | 咨询方式、讲座培训、60 分钟讲座安排、课程教学、入馆培训 |
| 科研支持 | 学科服务与联络馆员、代查代检、核心期刊导引 |
| 资源建设 | 资源荐购、书刊捐赠、学位论文提交 |
| 馆情与资讯 | 馆史沿革、机构设置与电话、服务项目、节假日与寒暑假开馆安排 |
| 近期公众号通知 | 官方公众号「北京服装学院图书馆」发布的最新活动、讲座与服务通知（经搜狗现取，仅限这一个账号） |
| 常见问题 | 校外访问两种入口（`w.bift.edu.cn`／`vpn.bift.edu.cn`）、企业微信扫码登录提示无权限的处理办法 |
| 文档类 | 规章制度条款、2018—2025 年度数据、校历周次日期、信息中心服务说明 |

它**不是**通用问答机器人：不使用模型自带知识、不联网搜索补路径、不代写论文、不评价资源优劣。唯一的站外来源是经身份核验的指定官方公众号（仅时效资讯类问题），其余一律以授权范围为准。资料未写即回答不知道；资料只写了一部分，就照录这一部分，不自行补全。当原文给出了明确规则（如截止日、开通周期、校历开学日）时，可在授权材料范围内做日期推算与逻辑推演，结论单独标注推算性质、注明出处与处理步骤，并以馆方或后台最终确认为准，不写成承诺。

## 安装与使用

**方式一：让智能体直接安装（推荐）**

打开 WorkBuddy 或其他支持安装 Skill 的智能体，把下面这个链接复制过去：

```
https://github.com/yiweiguo126/bift-library-reference
```

然后说：「帮我安装这个 SKILL」。智能体会拉取仓库并完成安装，装好即可直接提问。

**方式二：手动下载安装**

1. 下载或克隆本仓库。
2. 将整个目录（含 `SKILL.md`、`references/`、`scripts/`）放到 WorkBuddy 的 Skill 目录：
   - 用户级：`~/.workbuddy/skills/bift-library-reference/`
   - 项目级：`<项目目录>/.workbuddy/skills/bift-library-reference/`
3. 确认 `SKILL.md` 位于目录根部，且其 YAML front matter 完整。新开一个对话，直接用自然语言提问即可，Skill 会按描述自动加载。

例如：

- 「静音舱怎么预约？」
- 「教师阅享空间需要预约吗？」
- 「2026 年暑假图书馆开馆时间是什么？」
- 「2018 到 2025 年借阅量最高的 5 本书是哪些？」
- 「研究生能借几本书、借多久？」
- 「11 月 3 日申请的 WGSN 账号，什么时候能开通？」（按页面规则与校历推算）
- 「企业微信扫码登录 VPN 提示没权限怎么办？」（照录常见问题解决方法文档）

提问时不必使用栏目原名，Skill 会先做语义匹配；信息不足时它会只追问一个最关键的问题。每条答案末尾都附「参考原文出处」，便于核对。

## 信息源与回答边界

Skill 只读取四类材料：

1. `SKILL.md` 中登记的授权 URL（主站 `lib.bift.edu.cn` 公开页面，以及四条 OPAC 入口链接）；
2. `references/` 下的随附文档；
3. 用户在本次会话中明确提供并说明用途的临时文档；
4. 经身份核验的唯一指定公众号「北京服装学院图书馆」（微信 ID `BIFT_LIB`）文章——由 `fetch_wechat_search.py` 经搜狗现取，**仅限时效资讯类问题**，其他账号一律排除。

不在上述范围内的页面、域名、缓存与模型记忆一律不作为答案依据。开放时间、预约规则、借阅细则、最新资讯、馆情信息等定期更新的内容走动态接口现取，不固化为静态文本；时效资讯类问题先搜指定公众号、再以官网最新资讯补充与校验；规章制度、年度数据、校历与信息中心内容直接读本地文档。

授权材料中若出现校园网内地址（如 `10.104.x.x`），Skill 只按原文照录，不访问、不推测其内容，并将其呈现为不可点击的行内代码。这类地址仅在校园网环境中可用，公开仓库中的记录仅为原文忠实转写。

基于授权材料的统计、合并与日期推算／逻辑推演属于派生结果：Skill 会标明派生性质、逐项标注出处，并附 1—3 句处理说明；推算须满足三条件——原文规则明确、基础事实全部取自本轮实读的授权源（如学期起始月须实读校历，不凭常识假定）、步骤可回溯不跳步，结论以馆方或后台最终确认为准；口径不一致时并列保留原文，不替用户取舍。涉及资源使用方式与规章条款的原文仍完整照录，不因推算而扩写。

## 脚本（维护者使用）

动态栏目正文需现取，脚本仅依赖 Python 3 标准库：

```bash
python3 scripts/fetch_space_service.py --page open_time|yanxue|seat|locker|quiet
python3 scripts/fetch_study_research.py --page consult|lecture|lecture_60|lecture_topics|course|orientation|subject|retrieval|core_journals
python3 scripts/fetch_study_research.py --page recommend|donation|thesis
python3 scripts/fetch_study_research.py --page location|borrow_rule|proxy_borrow|cross_campus|interlibrary|doc_delivery
python3 scripts/fetch_library_info.py --page about|org|service
python3 scripts/fetch_news.py --list | --search 关键词 | --data-id <id>
python3 scripts/fetch_resource_list.py --search 关键词 [--type trial|feature|common|all]
python3 scripts/fetch_resource_detail.py --search 关键词 [--type trial|feature|common]
python3 scripts/fetch_resource_detail.py --url <详情页 URL> | --data-id <dataId>
python3 scripts/fetch_wechat_search.py --search "北京服装学院图书馆 <事项词>" [--days 90] [--top 20] [--fetch-original] [--json]
```

`--page all`、`--group` 之类的批量参数仅供馆员核对，单次作答不应使用。接口地址、页面 ID 与实例参数登记在 `SKILL.md` 对应章节，站点改版后由维护者核对更新。

数字资源的清单（常用／特色／试用）随资源新增与到期撤销变动，因此不逐条登记链接，改为运行时查清单接口取条目名、发布时间与详情页地址。资源详情页正文**内嵌在页面内联脚本的 `data.content` 字段**（2026-11-17 实测），`fetch_resource_detail.py` 静态解析即可取全文，与浏览器所见一致，无需渲染或浏览器；正文中的图片以［图片］占位，图片内文字不照录。仅在解析失败（退出码 3）时，Skill 才降级为「入口式回答」，给可点开的清单页与详情页链接由读者自行打开，不凭条目名推测内容。

## 维护与版本

**当前版本 v1.12（2026-11-23）**：**重要更新——允许基于原文的日期推算与逻辑推演，回复改为自然亲切的馆员口吻。** 原文规则明确时（如 WGSN 开通截止日、还书顺延的校历开学日）可推算到具体时点，结论标注「基于原文规则的推算」、与原文照录分区呈现、附处理步骤，以馆方／后台最终确认为准；推演须满足三条件（规则明确／基础事实取自本轮实读授权源／步骤可回溯），照录原文、标源、标性质等硬约束不放松。馆员补充惯例 C-1「顺延至开学之后」现可结合现行校历推算可还书时点，校历无下一学期开学日则不假定。口吻拟人化只改表达方式，不改事实边界。

**历史版本 v1.11（2026-11-23）**：新增 `references/常见问题解决方法.md`，登记校外访问两种入口（`https://w.bift.edu.cn`／`https://vpn.bift.edu.cn`）、企业微信（机构选「北京服装学院」）扫码登录，以及「暂无权限登录此应用，可联系公司管理员」报错的处理办法（企业微信左上角切换机构后重新扫码）；`SKILL.md` 增该本地文档路由，命中即照录作答。

**历史版本 v1.10（2026-11-19）**：在官方网站信息源基础上新增官方微信公众号来源（基于搜狗微信网页搜索）。时效资讯先检索唯一指定账号「北京服装学院图书馆」(`BIFT_LIB`) 近期文章，再与官网最新资讯补充／去重／冲突校验；公众号文章经账号核验后作为正式授权源照录，出处含标题／发布时间／可点开链接；`lookbook`／`look book` 自动归一化为「Look·Book」。所有动态接口脚本的 `sign` 改为运行时从栏目页读取（旧硬编码常量已失效），补上接口业务错误（`mh_engine_*`）显式报错。本 skill 独立分发、仅用于图书馆参考咨询。

**历史版本 v1.03（2026-11-17）**：优化「特色资源」与「试用资源」的获取与回复方式——两类资源不逐条登记链接，改由清单接口现取条目；详情正文改由 `fetch_resource_detail.py` 静态解析页面内联脚本取回，不再依赖浏览器渲染，取不到时才降级为入口式回答。

- 授权 URL、页面 ID、接口参数与硬规则集中在 `SKILL.md`，日常维护优先修改该文件。
- `references/` 中文档与馆方公开栏目内容保持一致；年度数据的源页直链保存在各年度 `skeleton.md`，原始图片不随仓库分发。
- 内部工作记忆、Python 编译缓存与系统元数据不纳入版本管理（见 `.gitignore`）。
- 本仓库使用 Git 进行版本管理；每次改动应提交清晰的变更说明。
